# Grocery Shopping Console

**Grocery Shopping Console** is a simple Java-based console application that simulates a grocery shopping experience. Users can add items to their cart, view prices, and calculate a total bill. The program runs interactively until the user decides to finish or exit.

## Installation Instructions

### Prerequisites

Ensure you have the following software installed:

- Java Development Kit (JDK) version 8 or higher.
- A Java IDE or any text editor (like VSCode, IntelliJ IDEA, or Eclipse).
